A **load balancer** is a single entry point that spreads incoming requests across several servers, containers or functions. It keeps checking each one's health and stops sending traffic to any that fail. Users always see one address; behind it you can add, remove or replace servers without anyone noticing.

Elastic Load Balancing (ELB) is the family of AWS load balancers. It's managed: AWS keeps it running and scales it to your traffic.

## Key ideas

<KeyConcepts>
  <Concept title="Application Load Balancer (ALB)">Works at the HTTP level (layer 7). It can route on path, host name, headers and query strings, and send traffic to EC2, containers, IP addresses or Lambda functions.</Concept>
  <Concept title="Network Load Balancer (NLB)">Works at the TCP and UDP level (layer 4). Built for very high throughput and low latency, with a fixed IP address per Availability Zone. Good for games and non-HTTP protocols.</Concept>
  <Concept title="Gateway Load Balancer">For putting third-party network appliances, like firewalls, in the path of traffic. Rarely needed in student projects.</Concept>
  <Concept title="Listener">A port and protocol the load balancer listens on (e.g. HTTPS on 443) and the rules for what to do with each request.</Concept>
  <Concept title="Target group and health checks">A target group is a set of servers (targets) that share a health check, e.g. "GET /health must return 200". Unhealthy targets get no traffic until they pass again.</Concept>
  <Concept title="With Auto Scaling">An Auto Scaling group registers new instances into the target group automatically, so the load balancer always knows the current fleet.</Concept>
</KeyConcepts>

## Where it would fit in our projects

Both projects use [API Gateway](/services/api-gateway) as their front door instead. For Lambda backends it does more out of the box: request validation, authorizers (DropVault's token check), throttling, and in [Quibble](/projects/quibble)'s case a WebSocket API. It also costs nothing when no one is using it, while a load balancer bills every hour.

A load balancer would appear if either app moved to [EC2](/services/ec2) or [ECS](/services/ecs-eks): an ALB in front of a few servers, with a health check on each.
