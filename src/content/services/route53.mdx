Route 53 is AWS's **DNS** service. DNS (the Domain Name System) is how a name like `quiz.example.com` becomes the address of the server or service that answers it. Route 53 answers those lookups for your domains, and you can also **register** (buy) domain names through it. The name is a nod to port 53, the port DNS uses.

Without a custom domain, AWS services give you long default names such as `abc123.execute-api.ap-south-1.amazonaws.com` or `main.d1abc.amplifyapp.com`. Route 53 is how you put your own name on them.

## Key ideas

<KeyConcepts>
  <Concept title="Hosted zone">The set of DNS records for one domain. A **public** zone answers the internet; a **private** zone answers only inside your VPCs. When you create a public zone, Route 53 gives you four **name servers** to set at your domain registrar.</Concept>
  <Concept title="Record types">**A** maps a name to an IPv4 address, **AAAA** to IPv6, **CNAME** to another name, **MX** to mail servers, **TXT** to text (used for verification).</Concept>
  <Concept title="Alias records">A Route 53 extra: an A or AAAA record that points straight at an AWS resource (API Gateway, CloudFront, a load balancer, an S3 website). Unlike a CNAME it works at the bare domain (`example.com`), and the lookups are free TODO(verify).</Concept>
  <Concept title="TTL">How long resolvers may cache an answer. Lower it before a planned change, so the new value spreads quickly.</Concept>
  <Concept title="Routing policies">**Simple** (one answer), **weighted** (split traffic by percentage), **latency** (nearest region), **failover** (backup when a health check fails), and **geolocation**.</Concept>
</KeyConcepts>

## How DropVault can use it

[DropVault](/projects/dropvault) has an optional custom API domain. Leave `api_domain_name` empty and you get the default `execute-api` URL. Set it (for example to `files.example.com`) together with `route53_zone_id`, and `terraform/domain.tf` does three things:

1. **Requests its own ACM certificate** for that name, with DNS validation.
2. **Writes the validation records into your hosted zone**, so ACM can see you control the domain and issue the certificate.
3. **Creates an alias A record** pointing your name at the API Gateway custom domain.

It's off by default, so the architecture diagram doesn't show it. [Quibble](/projects/quibble) uses the default AWS URLs only.

## Try it

DNS lookups work from any terminal:

<Command code={`nslookup aws.amazon.com`} />

List your hosted zones (and their record counts):

<Command code={`aws route53 list-hosted-zones --query "HostedZones[].[Name,Id,ResourceRecordSetCount]" --output table`} />
